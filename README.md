# 🕸️ Сквозь чащу

Party-игра для 2–5 игроков в духе Jackbox: большой экран (ноутбук + ТВ) показывает игру,
телефоны — контроллеры. Ведущий — паук-трикстер Ананси. Подробный дизайн — в `GDD_trickster.html`.

## Запуск

Нужен Node.js 18+.

- **Windows:** `start.bat`
- **macOS / Linux:** `./start.sh`

Скрипт соберёт оба клиента (только если код менялся) и запустит сервер. Дальше:

1. Открой на ноутбуке `http://<IP>:3001/screen` (адрес печатается в консоли) и выведи на ТВ.
2. Игроки сканируют QR-код телефоном — телефоны должны быть в той же Wi-Fi сети.
3. Каждый вводит имя и выбирает персонажа, ведущий жмёт «Начать игру».

Если IP определился неверно (VPN, Docker, несколько сетевых карт): `HOST_IP=192.168.1.42 ./start.sh`.

## Как устроена партия

```
ЛОББИ → ИНТРО → 11 вопросов (мини-игры после 3, 6, 9) → ФИНАЛЬНАЯ ГОНКА → ПОБЕДИТЕЛЬ
```

- **Вопросы:** 30 секунд, верный ответ +1 очко.
- **Помехи лидеру:** чем больше отрыв, тем сильнее Ананси мешает (перемешанные варианты, сброс первого выбора, блокировка, перевёрнутый экран).
- **Помощь отстающему:** при отрыве лидера ≥ 5 Ананси даёт +1 (до 3 раз; после ошибки помощь кончается).
- **Мини-игры:** Три тропинки, Голосование, Шпион (от 3 игроков), История Ананси, Крокодил. Перед каждой — правила; максимум 3 очка за игру.
- **Финал:** 12 клеток, стартовая клетка зависит от очков. Первый верный ответ +2 шага, остальные верные +1.

Ведущий на большом экране может: **⏭ Дальше** — пропустить таймер текущего этапа (например, когда шпиона уже обсудили), **↺** — вернуться в лобби, **⛶** — полный экран.
После финала — «Ещё партия» (те же игроки) или «Новые игроки».

Телефон можно перезагрузить, заблокировать или закрыть вкладку — при возврате игрок вернётся на своё место
с очками и ролью (сессия хранится в браузере).

## Структура

```
server/
  src/index.js        Express + Socket.io, раздача клиентов, QR
  src/engine.js       вся игровая логика (не зависит от транспорта)
  src/config.js       константы и тайминги
  src/content.js      тексты мини-игр, слова, персонажи
  src/minigames/*.js  серверные модули мини-игр
  data/questions.json база вопросов
  test/simulate.js    автотест: боты играют полные партии на виртуальном времени
client-screen/        React, большой экран (src/minigames/*/ScreenView.jsx)
client-phone/         React, телефон (src/minigames/*/PhoneView.jsx)
assets/               фоны, персонажи, музыка, звуки, голос Ананси (см. assets/README.md)
```

`src/shared/` в обоих клиентах — одинаковые файлы (подключение к серверу, таймер, словари).
Create React App не позволяет импортировать файлы вне `src`, поэтому они продублированы. Меняешь — меняй в обоих.

## Разработка

```bash
cd server && npm test            # прогон партий ботами (~1 сек)
TIME_SCALE=0.3 npm start         # все таймеры в ~3 раза быстрее — удобно проверять руками
```

Клиенты в режиме разработки (горячая перезагрузка): `npm start` в `client-screen` (порт 3000)
и в `client-phone` (порт 3002), сервер — на 3001.

### Добавить вопросы
`server/data/questions.json`: `{ "id": 100, "text": "...", "answers": ["А","Б","В","Г"], "correct": 0 }`.
`correct` — индекс верного ответа (0–3). Некорректные вопросы сервер пропускает и пишет в лог.

### Добавить мини-игру
1. `server/src/minigames/<id>.js` — по образцу `three_paths.js`, затем зарегистрировать в `minigames/index.js`.
2. `client-screen/src/minigames/<id>/ScreenView.jsx` и `client-phone/src/minigames/<id>/PhoneView.jsx` + записи в их `index.js`.
3. Название, описание и правила — в `MINIGAME_INFO` (`src/shared/constants.js` обоих клиентов).

Секреты (слово, роль) отдаются только через `privateData` — в `publicData` их класть нельзя: публичное состояние видят все.
