СКВОЗЬ ЧАЩУ

Party game • 4–8 игроков • Ананси ведёт игру

🕸️ Концепция

Большой экран — сервер, Телефоны — контроллеры.

Локальная сеть, подключение по QR-коду. Ведущий — Ананси, паук-трикстер из африканской мифологии.

🦎 Персонажи

🕷️ Паук 🐸 Лягушка 🐍 Змея 🪲 Жук 🦎 Ящерица

У каждого одна пассивная способность, отражающая природу существа.

Не решено: конкретные пассивки

🌿 Основной маршрут

15 точек, финиш на 15-й. Количество вопросов ≠ шаги: не ответил — не продвинулся.

Вопросы: один на большом экране для всех, отвечают на телефоне. Правильный ответ — шаг вперёд.

Мини-игры: триггерятся, когда лидер доходит до точек 3, 6, 9, 12. Ананси останавливает лидера, все замирают и играют. Чередование: короткая / длинная.

🎲 Мини-игры

⏳ Короткие

  • Три тропинки (удача)
  • Голосование про личность

🐊 Длинные

  • Шпион (не знает, что он шпион)
  • История Ананси (придумай финал)
  • Крокодил

⚡ Помехи для лидера

  • 3 шага отрыв — лёгкие помехи на телефоне
  • 4 шага — сильнее
  • 5+ шагов — ещё сильнее + комментарии Ананси
  • 8+ шагов — пасхалка: Ананси смиряется и перестаёт мешать

🤝 Помощь отстающему

Отрыв от остальных 6+ шагов — Ананси двигает на 1 шаг вперёд (максимум 2–3 раза за игру).

Если после помощи игрок отвечает неправильно — Ананси прекращает помогать.

🏁 Финальная гонка

Триггер: лидер достигает точки 15. Ананси открывает путь для всех.

Поле 12 шагов. Стартовые позиции:

  • 🏅 Лидер(ы) — клетка 4
  • 📍 Позиции 10–14 на маршруте — клетка 3
  • 📍 Позиции 5–9 — клетка 2
  • 📍 Позиции 1–4 — клетка 1

Механика: все отвечают одновременно. Первый правильный ответ — 2 шага, остальные правильные — 1 шаг. Помех нет, все на равных.

Не решено: как технически определяется «первый ответил» — нужна точная метка времени на сервере

🔄 Флоу игры

LOBBY → CHARACTER SELECT → INTRO → QUESTION ↔ QUESTION RESULT → MINIGAME INTRO → MINIGAME → RESULT → FINAL RACE INTRO → FINAL RACE → WINNER

* Мини-игры вклиниваются по достижении лидером точек 3,6,9,12. Финальная гонка — после точки 15.

🎨 Визуал

Большой экран — фон: тропинка в джунглях, уходящая вдаль (нейросеть / ассеты).
Миникарта слева: извилистая тропинка, иконки персонажей, точки вопросов, ✦ мини-игр.
Снизу — карточка с вопросом и вариантами. Декор: паутина Ананси, светлячки.

Телефон — варианты ответов крупно. Помехи для лидера: скачущие ответы, перевёрнутый экран. Подсказка для отстающего.

Шрифты: Cinzel для заголовков, Nunito для текста.

Цвета: тёмно-зелёный фон, золотые акценты.

🛠️ Технический стек

  • Бэкенд: Node.js + Socket.io
  • Фронтенд: React
  • Подключение: локальная сеть, QR-код с локальным IP
  • Вопросы: локальный JSON

📋 План разработки

  1. Этап 1 — Скелет (1–2 нед.)
    Сервер, лобби, QR, выбор персонажа, один вопрос, позиции.
  2. Этап 2 — Основной маршрут (2–3 нед.)
    Цикл вопросов, миникарта, помехи, помощь, комментарии Ананси.
  3. Этап 3 — Мини-игры (2–3 нед.)
    Три тропинки, голосование, шпион, история, крокодил, триггеры.
  4. Этап 4 — Финальная гонка (1 нед.)
    Поле, стартовые позиции, механика первого ответа.
  5. Этап 5 — Полировка (2 нед.)
    Анимации, звуки, фон, пассивки, тестирование с живыми игроками.

❓ Нерешённые вопросы

  • 🕸️ Пассивки персонажей
  • ⏱️ Механика «первого ответа» в финале — метка времени на сервере или клиенте
  • 🖼️ Финальный фон — нейронка, готовые ассеты или другое
  • 🏎️ Механика финальной гонки — утверждена ли схема «первый правильный = 2 шага»
